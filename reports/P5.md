# P5 Hardening

## Key points
- Offline mode was simulated: a second server whose outbound traffic goes to a dead proxy, plus a browser that aborts every non-localhost request. Results: globe on Natural Earth II, "Offline" pill, 4 stories, and Palm, Lake Mead, Arabic Palm and Dubai Marina all answered from disk (Dubai Marina from its earlier live cache).
- Esri failure (arcgis hosts blocked): Esri layer hidden, warning card plus "Imagery: Natural Earth II · Esri unavailable" pill. Console shows only the 2 blocked requests.
- WebGL loss (`WEBGL_lose_context`): full-bleed fallback with the 4 story cards, and the chat still answers. Cesium logs one shader-compile error from the frame already in flight; after that the render loop stops.
- Hotkeys 1/2/3 run Palm 2001→2008, UAE flood 2024 and Lake Mead (checked headless). C closes the chat and the canvas resizes to 1280. Under 900 px the chat is a full-screen sheet with no horizontal scroll.
- `start_demo.bat` was run non-interactively: it starts Ollama, warms the 7B ("model warm"), waits for the API ("API ready") and opens Chrome with `--start-fullscreen`.
- `setup.bat`, `README.md` and `DATA_SOURCES.md` are written.

## Bugs found and fixed here
1. A cold 7B load is longer than the 6 s chat timeout. Each answer then fell back to the 4B, which evicted the 7B: about 12 s per answer. Fixes: server-start warm-up (additive thread in `extras.py`), warm-up in `start_demo.bat`, and `LLM_FALLBACK`/`LLM_SMALL` empty, so one resident model with rules and templates as the fallback. After: Lake Mead 2.0 s with an LLM interpretation.
2. The LLM tied "Dubai Marina" to the Palm preset. The stream now drops an LLM-chosen preset unless the place matches that preset's aliases.
3. With a previous map open, the 7B labelled new questions `explain_last` and re-showed the old analysis. The stream only accepts `explain_last` from the rule router.
4. Nominatim returned 403 for the placeholder `example.com` User-Agent. `.env` sets a generic UA; the README asks the team to add a contact email.
5. Asking before the globe finished booting crashed `flyTo`. `ask()` now waits for boot, `/api/config` times out at 4 s, and the globe API is a no-op without WebGL.
